# 📦 商品贴换标加工转换工具

本工具主要用于处理发货场景下的"同 SKU 不同 FNSKU"的库存瀑布流扣减，并自动生成标准的贴换标加工单据。

本项目基于 Python + Streamlit 构建，支持一键部署至 [Streamlit Community Cloud](https://streamlit.io/cloud)，免费托管，所有数据处理均在浏览器端本地完成，确保业务数据的安全与高效。

---

## ✨ 核心特性

- **🚀 一键云端部署**：推送到 GitHub 后，在 Streamlit Community Cloud 上免费托管，国内外均可访问。
- **📊 可编辑数据表格**：基于 Streamlit `data_editor`，支持直接编辑、批量粘贴、动态增删行。
- **🧠 智能瀑布流扣减算法**：自动优先匹配同 FNSKU 库存，最大程度减少物理换标的加工作业量。
- **📑 智能双 Sheet 导出**：正常单据与异常（缺货）单据自动分流，方便仓库操作与前端采购补货。
- **🏷 动态字段映射**：法人主体、库区等字段从库存源数据动态读取，支持智能映射。

## 📥 一、 输入端说明

本工具的运行依赖两个维度的输入数据：**在库库存明细表** 与 **转换需求**。

### 1. 源数据：在库库存明细表
用户需通过界面上传最新的库存表格（支持 `.xlsx`, `.xls`, `.csv`）。
系统读取时，**严格依赖以下列名**（需保证大小写与文字完全一致）：
* `法人主体`（优先读取，若不存在则回退读取 `库存主体`）
* `仓库名称`
* `SKU`
* `FnSKU`（注意大小写）
* `可用库存`
* `库区`

### 2. 交互录入：转换需求表
用户在页面表格中录入加工需求，支持从外部 Excel 直接复制粘贴：
* `SKU`：目标商品编码（必填）
* `目标 FNSKU`：期望转换成的终态 FNSKU（必填）
* `需求数量`：需要加工的商品总数（必填，>0）
* `备注`：辅助说明（选填，仅作录入参考，不输出至最终单据）

## ⚙️ 二、 核心处理逻辑 (瀑布流匹配)

当用户点击"执行匹配并导出转换表"后，系统将按以下严格逻辑进行数据运算：

### 1. 数据清洗与前置过滤
系统首先对上传的《在库库存明细表》进行硬性条件过滤，构建**有效库存池**：
- 仅保留 `仓库名称` = **DLM供应链深圳仓-SZ**
- 仅保留 `可用库存` > **0** 的记录

### 2. 法人主体智能映射
输出的 `法人主体` 字段从库存源数据动态读取，并按以下规则映射：
- 优先读取 `法人主体` 列，若不存在则回退读取 `库存主体` 列
- 若值包含"**深圳市德拉姆供应链有限公司**"，统一输出为"深圳市德拉姆供应链有限公司"
- 其他值保持原样输出

### 3. 优先级排序与物理豁免判定
针对每一条需求，在"有效库存池"中寻找对应的 SKU 库存：
- **优先级判定**：优先使用源库存中 `FnSKU` 与需求的"目标 FNSKU"**不同**的库存进行扣减（先消耗需要换标的库存）。
- **豁免判定**：如果扣减的这部分库存其原始 FnSKU 与目标 FNSKU 相同，说明这批货在物理上**无需重新贴标**，因此这部分扣减记录**不会**生成在最终的加工单据中。

### 4. 瀑布流库存扣减
- 若需要换标的 FNSKU 库存不足，系统将自动继续扣减该 SKU 旗下**其他 FNSKU** 的可用库存，直到满足"需求数量"或该 SKU 的总可用库存耗尽。
- 被扣减的其他 FNSKU 库存，将被视作需要"物理换标"的加工对象，记录入输出结果中。

## 📤 三、 输出端说明 (Excel 导出格式)

工具会自动生成一个包含多个 Sheet 的 Excel 文件（`.xlsx`），实现正常加工与异常登记的分流。

### Sheet 1: 转换单 (正常发给仓库作业)
仅输出匹配成功且**原始 FnSKU 与目标 FNSKU 不一致**（即确实需要人工去贴换标）的数据。
- **格式严格限定为 9 列**：
  1. `转换类型` （固定为"贴换标"）
  2. `法人主体` （从库存源数据动态读取并智能映射）
  3. `仓库` （固定为"DLM供应链深圳仓-SZ"）
  4. `SKU1` （加工对象 SKU）
  5. `库区1` （从库存源数据的 `库区` 字段动态读取）
  6. `FNSKU1` （源库存 FnSKU）
  7. `数量` （实际扣减/需换标数量）
  8. `SKU2` （加工结果 SKU，与 SKU1 一致）
  9. `FNSKU2` （目标 FNSKU）
- **注意**：第一行为固定注释文本，第二行为上述表头，第三行起为数据明细。

### Sheet 2: 库存异常(缺货) (仅在发生不满足时生成)
当某个 SKU 的总有效可用库存 < 需求数量时，系统会自动生成此 Sheet。
- **格式限定为 10 列**（前 9 列与 Sheet 1 相同，第 10 列为异常说明）：
  - 第 10 列 `备注`：详细记录缺口情况，格式例如：`不满足，总需228，只有100，缺128`。
- 该表主要用于业务复盘、补货提醒及异常追溯。

## 🚀 五、 部署方式

### Streamlit Community Cloud（推荐，免费）

1. 将本项目推送到 GitHub 仓库
2. 登录 [share.streamlit.io](https://share.streamlit.io)
3. 点击 "New app"，选择对应的 GitHub 仓库
4. 主文件设置为 `app.py`，点击 "Deploy"
5. 部署完成后获得 `https://你的应用名.streamlit.app` 链接，分享给他人即可使用

### 本地运行

```bash
pip install -r requirements.txt
streamlit run app.py
```
